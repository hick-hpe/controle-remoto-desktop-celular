# 📱 QR Code Pair & Remote Control (Node.js + Socket.io)

Este projeto implementa uma arquitetura moderna para **pareamento de dispositivos e controle remoto em tempo real** através de um QR Code gerado dinamicamente. Ele separa de forma isolada as sessões de múltiplos navegadores (Desktop vs Celular) utilizando o `express-session` compartilhado nativamente com o servidor `Socket.io`.
